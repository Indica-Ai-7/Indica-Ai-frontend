# Tarefa — Etapa 1: Catálogo e API HTTP local

## Objetivo
Definir o contrato de dados e disponibilizar o catálogo inicial por HTTP via JSON Server.

## Tarefas
- [ ] Definir schema dos títulos (campos, tipos, obrigatoriedade e validações mínimas).
- [ ] Estruturar `db.json` por recursos (ex.: títulos, tipos/categorias auxiliares se necessário).
- [ ] Garantir IDs estáveis e únicos para todos os registros.
- [ ] Consolidar pelo menos 200 obras reais por tipo: filme, série, documentário, animação e novela.
- [ ] Remover duplicações e inconsistências básicas (tipo inválido, ano fora de formato etc.).
- [ ] Configurar JSON Server para servir o catálogo por HTTP.
- [ ] Documentar endpoints e exemplos de consulta.
- [ ] Documentar origem dos dados, licença/permissões e atribuições exigidas.
- [ ] Registrar bloqueio formal caso a meta de volume/licença não seja viável.

## Critérios de aceite
- API local responde aos endpoints documentados.
- Registros obedecem ao contrato de dados.
- Quantidade mínima por tipo é comprovável.
- Fontes e permissões de reutilização estão documentadas.

## Dependências
- Nenhuma (início do fluxo).
